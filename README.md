# Sanggar Alam – Website Jasa & Produk Taman

Website **Sanggar Alam** adalah aplikasi web berbasis **Next.js (App Router)** yang digunakan untuk menampilkan layanan dan produk seperti **kolam taman, relief dinding, dan patung taman**.

## Persiapan Sebelum Menjalankan

Install:

- **Node.js** ≥ 18
- **npm** atau **yarn**
- Backend API sudah berjalan (atau menggunakan API publik)

---

## Cara Menjalankan Project

### Clone Repository
```bash
git clone https://github.com/restuanggia-del/sanggarAlam.git
cd sanggar-alam

Install Dependency
npm install
# atau
yarn install

Jalankan Development Server
npm run dev
# atau
yarn dev

Buka di Browser
http://localhost:3000 //admin
http://localhost:3001 //toko

Build untuk Production
npm run build
npm start
